# 状态机盘点

这个项目没有路由库、状态库或后端。页面行为由若干小型状态机组成，其中一部分此前散落在组件的 `useState` / `useEffect` 里（隐式），本次重构把会话相关的部分收进了 `src/domain/`（纯规则）和 `src/hooks/`（会话状态），组件只做渲染。

下面按运行时顺序列出所有状态机。标“显式”的已有类型或纯函数承载；标“局部”的仍是组件内的简单 UI 状态。

## 总览

| # | 状态机 | 状态 | 主要事件 | 位置 |
|---|---|---|---|---|
| 1 | 页面路由 | home / practice(kind) / exam / wrong / favorites / stats | 首页入口、返回首页 | `App.tsx` `Route`（显式） |
| 2 | 题库资源 | loading / ready / error（按题库缓存） | 进入题库、加载成功/失败、切换题库 | `hooks/useBank.ts`（显式） |
| 3 | 外观偏好 | system / light / dark | 切换按钮、系统主题变化 | `hooks/useTheme.ts`（显式） |
| 4 | 练习会话 | loading / error / ready（空 / 进行中）/ 完成 | 进入练习、恢复断点、完成 | `hooks/usePracticeSession.ts` + `domain/practice.ts`（显式） |
| 5 | 单题作答 | 未选 / 已选草稿 / 已判（对或错） | 选项、查看答案、即时判题 | `applyPracticeSelection` / `applyPracticeCheck`（显式） |
| 6 | 练习推进 | 第 1…n 题 / 最后一题 | 上一题、下一题、拖动、搜索跳转 | `usePracticeSession`（显式） |
| 7 | 考试会话 | loading / 答题中 / 已交卷（手动或超时）/ 结果 | 开始、退出、交卷、倒计时归零 | `hooks/useExamSession.ts` + `domain/exam.ts`（显式） |
| 8 | 考试单题 | 未答 / 已答 + 已标记 / 未标记 | 选项、标记、答题卡跳转 | `useExamSession`（显式） |
| 9 | 错题本条目 | 不存在 / 存在（错误次数 n） | 答错、错题练习答对、手动移除 | `domain/collections.ts` + `useCollections`（显式） |
| 10 | 收藏条目 | 未收藏 / 已收藏 | 星标按钮、列表移除 | 同上（显式） |
| 11 | 练习设置 | 即时判题开/关、选项乱序开/关 | 开关 | 随练习断点持久化（显式） |
| 12 | 结果筛选 | 只看错题 / 全部题目 | 结果页标签 | `Result.tsx`（局部） |
| 13 | 搜索面板 | 关闭 / 打开（空查询 / 有结果 / 无结果） | 搜索按钮、输入、Enter、Esc、点击结果 | `Practice.tsx` + `SearchPanel.tsx`（局部） |
| 14 | 答题卡 | 收起 / 展开 | 答题卡按钮、跳题、交卷 | `Exam.tsx`（局部） |
| 15 | 存储模式 | v1 数字答案 / 旧版字母答案 | 读取断点 | `storage.ts` 迁移（显式） |
| 16 | 题库 key 身份（构建期） | 新增 / 复用 / 删除 | `npm run data:build` | `scripts/build-data.mjs` + `data/key-map.json` |

## 1. 页面路由

```text
home ──顺序/随机/错题/收藏练习──> practice(kind)
home ──模拟考试──────────────> exam
home ──错题本 / 收藏 / 统计────> wrong | favorites | stats
任意页 ──首页 / 返回──────────> home
```

此前是 `view` + `practiceKind` 两个独立状态，存在“practice 但 kind 过期”的无效组合。现在是一个判别联合 `Route`，`practice` 必须携带 `kind`。

考试页退出有未交卷确认；练习页退出只保存断点，不弹窗。

## 2. 题库资源

```text
loading ──成功──> ready
   └────失败──> error
切题库 / 重新进入：回到 loading；离开时取消回调
```

- 每个题库的 Promise 缓存在 `data.ts`，成功后切回不重复请求；失败会从缓存删除。
- `error` 显示错误与返回按钮；`ready` 但题目为空在练习/考试页表现为空状态。
- `__DATA_VERSION__` 只影响 URL，不改变状态机。

## 3. 外观偏好

```text
preference = system ──系统深色/浅色──> 解析为 dark / light
preference = system ──点击切换──────> 显式 light 或 dark（写入 localStorage）
preference = light|dark ──系统变化──> 忽略
preference = light|dark ──点击切换──> 另一个显式值
```

- 主题键 `ham-exam-cn:theme` 故意在 `ham-exam-cn:v1:` 前缀之外：清空学习数据不会重置外观。
- 首屏由 `index.html` 的内联脚本在绘制前写入 `data-theme`，React 挂载后由 `useTheme` 接管。

## 4. 练习会话

```text
loading ──题库就绪──> ready
   │                    ├── order 为空 -> 空状态（错题本/收藏为空）
   │                    └── order 非空 -> 进行中
   ├──加载失败──> error
   └──题库/类型变化──> loading

进行中 ──完成（最后一题）──> 清除断点，返回首页
进行中 ──返回──────────────> 保留断点，返回首页
```

`planPracticeSession` 决定新开还是恢复：

- `saved.kind` 必须与当前练习类型一致。
- 顺序练习：恢复索引和答案，但顺序始终按题库重建。
- 随机练习：优先复用保存的顺序；没有有效顺序才重新洗牌。
- 错题/收藏练习：已保存的题排在前面，新加入集合的题追加在后；题库中已不存在的 key 被丢弃。
- 错题/收藏练习只有在“尚未全部判完”时才恢复；全部判完视为新一轮。
- 选项乱序的种子随断点保存，所以恢复后显示顺序不变。

## 5. 单题作答

```text
未选 ──选项──> 已选草稿 ──查看答案──> 已判（对/错）
  │                 │
  │                 └──即时判题且单选──> 已判（对/错）
  │
  └──查看答案（未选）──> 已判，但不计练习统计、不进错题本
已判 ──选项/查看答案──> 忽略
```

- 单选：选中即替换；多选：点击切换。
- 即时判题只对单选自动判；多选仍需“查看答案”。
- 已判后选项禁用，解析展开。
- “模糊”是正交标记，不影响判题；可随时切换。
- “收藏”也是正交状态，只改收藏集合。

## 6. 练习推进

```text
index: 0 … n-1
上一题 / 下一题：clamp 到边界
拖动进度条：跳到 1…n
搜索：跳到命中的 key，并关闭搜索面板
最后一题：主按钮从“下一题”变为“完成”
```

## 7. 考试会话

```text
loading ──题库就绪──> 答题中
   ├──加载失败──> error
   └──题库变化──> loading

答题中 ──手动交卷（确认）──> 已交卷
答题中 ──剩余时间归零────> 已交卷（自动）
答题中 ──退出（确认）────> 保存断点，返回首页
已交卷 ──> 结果页（筛选、回顾）
```

- 恢复条件：`endAtMs` 仍在未来，且保存的每个 key 都还在题库；否则重新组卷。
- 组卷：按规则抽取单选/多选，再整体洗牌；题库不足时生成较短的试卷。
- `result !== null` 即“已交卷”，不再维护独立的 `finished` 布尔值。
- `submittedRef` 防止手动交卷与超时交卷重复执行。
- 交卷时：答错的已答题目进错题本；未作答不计入错题本，但计分时算错。
- 计时器每秒触发一次 `now`，`remaining <= 60s` 只改变样式，不改变状态。

## 8. 考试单题

```text
未答 ──选项──> 已答 ──选项──> 已答（单选替换 / 多选切换）
已答/未答 ──标记──> 翻转标记（与是否作答正交）
答题卡：当前 / 已答 / 已标记 三个独立视觉状态
```

跳题会关闭答题卡；交卷也会关闭。

## 9. 错题本条目

```text
不存在 ──练习/考试答错──> 存在 (wrongCount = 1)
存在   ──再次答错──────> wrongCount + 1，刷新 lastWrongAt
存在   ──错题练习答对──> 不存在
存在   ──列表“移除”────> 不存在
```

- 同一轮练习里一道题只判一次，所以一次作答最多加一次。
- 条目只存 key、题号、摘要和时间；正文从题库按 key 取。
- 题库更新后 key 消失：列表仍显示摘要快照，进入练习时会被过滤掉。

## 10. 收藏条目

```text
未收藏 ──星标──> 已收藏（记录 createdAt）
已收藏 ──星标 / 列表“移除”──> 未收藏
```

收藏不参与判题，也不影响错题本。

## 11. 练习设置

```text
即时判题：关 <-> 开
选项乱序：开 <-> 关
```

两者都随练习断点保存；选项乱序关闭时按题库源顺序显示，但显示标签仍按位置生成 A/B/C/D。

## 12. 结果筛选

```text
只看错题（默认） <-> 全部题目
```

纯展示状态，不写存储。切换不改变分数、错题集合或错题本。

## 13. 搜索面板

```text
关闭 ──搜索──> 打开
打开 ──输入为空────> “输入题号或关键词”
打开 ──有匹配──────> 结果列表（最多 30 条）
打开 ──无匹配──────> “没有找到匹配题目”
打开 ──点击结果 / Enter / Esc / 点遮罩 / 关闭──> 关闭
```

搜索只在顺序练习提供；跳转后保留当前作答状态。

## 14. 答题卡

```text
收起 <-> 展开
展开 ──点击题号──> 跳到该题并收起
展开 ──交卷──────> 收起
```

## 15. 存储模式与迁移

```text
读取 practice / exam：
  answers 全是数字 id ──> 使用
  answers 含旧字母 A-D ──> 视为无效，丢弃断点
  无 answers ───────────> 允许（空断点）

错题本、收藏、统计不参与这次迁移，始终保留。
```

- 前缀 `ham-exam-cn:v1:` 覆盖练习、考试、题库选择、错题本、收藏、统计。
- “清空本地数据”删除该前缀下的所有键，然后整页重载（相当于回到初始状态）。
- 主题键不在前缀内，单独保留。

## 16. 题库 key 身份（构建期）

```text
题目内容（含原始选项字母）──hash──> 命中 key-map ──> 复用 key
                              └──未命中────> 分配新 key
旧 key 不再出现 ──> 从 key-map 删除（历史 key 不复用）
```

选项 id 从字母改成数字后，hash 仍然使用原始字母内容，因此题目 key 和 `key-map.json` 保持不变；这也是旧练习断点失效、而错题本/收藏仍能按 key 命中的原因。

## 不变量

- 一个页面同一时刻只挂载一个视图，因此每个会话 Hook 只有一份实例。
- `revealed` 的题不再接受选项；未作答直接查看答案时，不产生统计和错题记录。
- 错题本/收藏的写操作都通过 `useCollections` 的 reducer，持久化在提交后的 effect 中执行；严格模式下不会重复计数。
- 会话数据按 `bank + kind` 归属，切换题库或练习类型时不会误用上一份内存状态。
